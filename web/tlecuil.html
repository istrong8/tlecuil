TLECUIL · First-Order Fission Surface Power Sizer

Tlecuilli (Nahuatl): the three-stone hearth. This page runs the same equations as tlecuil.py (v0.2.1), and a parity check confirms both give identical results. There is no power limit: type any value in a number box. Areas are total radiating area (both faces) including margin, the convention NASA uses. Presets load published NASA design points and show the published values for comparison.
